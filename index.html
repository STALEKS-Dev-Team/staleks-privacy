Privacy Policy — Staleks Translator

Last updated: October 6, 2026

Overview

Staleks Translator is a Chrome extension for internal use by Staleks company employees. It assists with translating and rephrasing text within Google Slides, Google Sheets and Google Docs using professional beauty industry terminology.

Data We Collect

We do not collect, store, or share any personal data. The extension does not track users, does not use analytics, and does not transmit any identifying information.

How the Extension Works

  • Text copied to the clipboard by the user is sent to a private internal API server for translation or rephrasing.
  • The API server processes the text and returns a result. The text is not stored on the server.
  • Panel position and language preferences are saved locally in Chrome storage on the user's device only.

Permissions Used

  • clipboardRead / clipboardWrite — to read text for translation and write the result back.
  • storage — to save panel position and language settings locally.
  • activeTab — to inject the translation panel into Google Slides, Sheets and Docs pages.
  • host permissions — to send text to the Staleks internal API server for translation. Several server addresses are listed because the service is being migrated to a new hosting provider; the previous address is kept as a fallback during the transition.

Third Parties

The extension communicates only with the private Staleks internal API. No data is shared with any third-party services.
